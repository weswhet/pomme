## Cross-cutting: failed results on stderr with `Error:` (#12a) — `253dec0`

Helper-returned failures were printed to stdout with no marker while thrown
errors went to stderr as `Error: …`. The table writer now classifies each
result once: byte-carrying results keep their frame routes, successful text
stays on stdout, and failed text goes to stderr as `Error: <text>`. The eight
formatters that spelled their own `ERROR:` drop it; the TUI supplies the
marker itself.

Live: `sessions inspect t1 <missing>` → stdout empty, stderr
`Error: The terminal session was not found.`, exit 1. `jobs kill` on an
unknown ID → `Error: Pomme agent request failed (not-found): …` on stderr.

## Cross-cutting: negative option values (#9) — `d3197bd`

Every numeric option parses unconditionally, so `-1` is captured and the
range check names the problem. `TimeoutOptions` validates at parse time;
start/restart move their guard into validation; click coordinates and
session offsets gain the range checks they lacked.

Live: `ui click t1 --x -1 --y 1` → `--x must be a finite display coordinate
of zero or more.`, exit 64; `jobs wait t1 <id> --timeout -1` →
`--timeout must be greater than zero.`, exit 64; `ipsw list --limit -1` and
`cat t1:/x --offset -1` likewise.

## Cross-cutting: identifier kinds (#10) — `d89a3be`

`validateIdentifier(_:kind:)` words a rejection for the VM, snapshot,
template, or config-derived name that was actually invalid. The VM wording is
byte-identical to before.

Live: `snapshot create t1 "bad/snap"` → `Error: Invalid snapshot name
bad/snap. Use 1-64 …`; `template create "bad/t"` → `Invalid template name`.

## 8. `NAME:/absolute/path` placeholder — `253c98c`

The four `cp`/`cat` strings that used `vm` as a literal placeholder now read
`NAME:/absolute/path`; the `cat` rejection carries an example.

## 1. `--parallel` — `b772ee6`

`--parallel` is a bare flag meaning two installs at once, the framework's
two-macOS-guest limit; the hidden `--parallel-limit` is gone and the executor
refuses more than two. A count after the flag gets
`--parallel takes no value; config creation runs at most two VMs at once.`

Live: `create --config good.yaml --dry-run --parallel 2` → that message,
exit 64 with the `create` usage; bare `--parallel` plans `cfgtest-26.6.2`.

## 2. `exec` and `POMME_VM_NAME` — `7a690dc`

The command uses the post-terminator strategy; the name can only come from
before `--`. `pomme exec t1 /bin/echo hi` without `--` is now rejected.

Live: `POMME_VM_NAME=t1 pomme exec -- /bin/echo hi` → `hi`, exit 0.

## 3. `cp` into a directory — `f76f7bd`

A guest destination ending in `/`, and a host destination that ends in `/` or
is an existing directory, receive the source's base name before any agent
traffic.

Live: `cp h.txt t1:/tmp/` → `Copied 6 bytes.`; `cat t1:/tmp/h.txt` → `hello`;
`cp t1:/tmp/h.txt out/` and `cp t1:/tmp/h.txt out` → `out/h.txt`;
`cp h.txt t1:/tmp/h2.txt` unchanged.

## 4 and 5. Job lines — `023ca2f`

Guest request text goes through one function. A detached start and a job
status render on the `jobs list` line shape; inspect adds `outputPending`.
The foreground timeout text points at `jobs list`, `wait`, and `kill`.

Live: `exec t1 -d -- /bin/sleep 30` → `RUNNING <id> pid=626`; `shell t1 -d
'sleep 30'` → same shape; `jobs inspect` → `RUNNING <id> pid=626
outputPending=false`, and after `jobs wait` → `EXITED <id> pid=626 exit=0
outputPending=false`; `exec --timeout 1 -- /bin/sleep 5` → exit 124 with the
new sentence on stderr.

## 6 and 7. Terminal session failures and transcript range — `9e397e6`

Terminal session text reads a failure envelope's message before any summary.
The transcript store distinguishes an offset beyond the end and the helper
carries the offset and length in the envelope, so the CLI names the range.
Offset equal to length still returns empty output.

Live: `sessions logs t1 <id> --from-offset 999999` → `Error: --from-offset
999999 is beyond the transcript end (0 bytes).`, exit 1; `--from-offset 0`
→ empty, exit 0.

## 12b. `pomme ui keys` and named key errors — `60ecf25`

The key names live in one table that `lookup` reads; `pomme ui keys` prints
it (table or JSON) without a VM. A rejected key names the token and, in a
sequence, its index.

Live: `ui key t1 bogus-key` → `Error: Unsupported key 'bogus-key'. Run
\`pomme ui keys\` for the supported names.`; `ui key-sequence t1 shift a` →
`… 'shift' at index 0 …`; `ui key t1 cmd+shift+t` and `ui key-sequence t1
left right` → `OK`.

## 20. Dry-run memory minimum — `b666146`

Every create path applies a 4 GiB floor before any download, and a dry run
applies the image's own minimum whenever the image is local (a
`--restore-image` path, a cached IPSW, or a template's recorded image),
reporting `memoryMinimum: {bytes, provisional}`. Disk is deliberately
unchecked: no reliable minimum is known.

Live (no VM needed): `create dtest --version latest --memory 512MB --dry-run`
and `create dtest --from-template mdmready --memory 512MB --dry-run` → `The
configured RAM 536.9 MB is below the provisional guest minimum 4.29 GB. …`,
exit 1. With `--memory 4GB` the template dry run reports the exact minimum
from the cached image (`provisional: false`), and the `latest` (27.0, not
cached) dry run reports `provisional: true`.
